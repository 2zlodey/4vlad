# Совместимость с Orkestr.DevicesEmulator — 2026-11-07

## Установка

Распаковать содержимое этого архива в корень существующего `scanner_node`, заменив файлы. Здесь только изменённые и новые файлы; это не полный проект. Пересобрать и перенести новый исполняемый файл на Raspberry Pi. Старый бинарник от замены исходников не изменится.

```sh
cmake -S . -B build
cmake --build build -j4
```

Существующие внешние зависимости (соседние cJSON и device.json) остаются нужны.

## Что исправлено

- VER: 14 байт = исходный request_id (4 байта LE) и 10 байт ASCII версии. Удалён ошибочный opcode в ответе.
- После ответа сессии включается общий цикл команд: VER допускается повторно и не обязан быть первой командой. Старый параметр --ver-timeout принимается для совместимости со скриптами, но не используется.
- Измерение 0x02: ответ 8 байт без status.
- Диапазон 0x03: запрос 14 байт без шага, ответ 12 байт с одной частотой и мощностью, без status.
- Ответ сессии: принимается минимум 52 байта, дополнительный хвост игнорируется.
- Разрешены разные исходные UDP-порты настроенного IP сервера. Ответ возвращается отправителю конкретного запроса, в том числе при очереди команд. Другие IP отбрасываются.
- При первом стандартном измерении автоматически выбирается доступный RX и настраиваются отсутствующие параметры. По умолчанию 2 MS/s, полоса 1.75 MHz с учётом ограничений SDR; HackRF/Stub: LNA=16 dB, VGA=16 dB. Явные настройки сохраняются, bladeRF использует усиление backend по умолчанию.
- Обновлены mock-сервер, проверки и описание протокола. Дополнительные команды настройки SDR сохранены.

## Принятые решения

Шаг диапазона: max(1000, ceil((stop_khz-start_khz)/127)) kHz. Обе границы включены, максимум 128 измерений; для одинаковых границ — одно. Возвращается центр окна с наибольшей измеренной мощностью; при равенстве — первая точка. Приёмник остаётся на последней просканированной частоте. Это грубый ограниченный поиск, не гарантирующий обнаружение узкого сигнала на широком диапазоне.

Мощность — нормированная средняя мощность IQ в сотых dBFS, без калибровки в dBm. При ошибке SDR стандартные кадры 0x02/0x03 не имеют поля status: ошибка пишется в лог, ложный успешный результат не отправляется. Сервер получит таймаут.

Версия VER по умолчанию `1.1.0.0`: соответствует AssemblyVersion проекта эмулятора и фактической реализации SoftwareVersion в приложенной DLL. VERSIONING.md эмулятора описывает три цифры, но не соответствует этой DLL. Если версия работающего сервера иная, передать `--software-version ТОЧНАЯ_ВЕРСИЯ`.

Порт по умолчанию 2653, как у эмулятора. Если установленный сервер слушает другой порт, указать его явно. Требования UDP/NAT к обратному доступу на объявленный локальный порт сохраняются.

Для физического развёртывания, где недопустимы синтетические данные при отсутствии SDR, собирать с `-DSCANNER_ENABLE_STUB_SDR=OFF`.
